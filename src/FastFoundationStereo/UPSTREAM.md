# Vendored upstream

This directory contains the runtime source and deployment scripts from
[NVlabs/Fast-FoundationStereo](https://github.com/NVlabs/Fast-FoundationStereo),
commit `a290ba04c1b3ad1ec41a33974a157b2917b624d4` (2026-09-09 checkout).

Large demo media and generated sample output are intentionally omitted. Model
weights are not redistributed; download one of the official checkpoints as
described in `readme.md` and place it below `weights/`.
